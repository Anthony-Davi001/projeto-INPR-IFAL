# Projeto final - INPR IFAL
### Aluno: Anthony Davi Santos Vieira

Projeto feito para obtenção de nota na disciplina de Introdução a programação no Instituto Federal de Alagoas.

---

## No que consiste o projeto?

É um objeto de aprendizagem simples e sólido para a aprendizagem do simple present em inglês. Contando uma explicação breve e dois minigames divertidos para testar os conhecimentos e ao mesmo tempo, ajudando a identificar os erros. 

## Para executar:

Clone o repositório:

```bash
git clone https://github.com/Anthony-Davi001/projeto-INPR-IFAL.git

cd projeto-INPR-IFAL
```

O projeto não vem com nenhuma dependência além do python. Portanto, basta executar o arquivo `main.py`:

```bash
python3 main.py
```
